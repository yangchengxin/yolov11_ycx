# yolo11 trt 推理范式
| 模式                                                                                  | pipeline                              | 优势                   | 劣势                 | 
|-----------------------------------------------------------------------------------|---------------------| ---------------------|--------------------| 
| trtx                                                                                  | pt ---> wts ---> engine               | 针对一些tensorrt库中不支持的特殊算子或者模块，我们可以通过plugin来实现并插入模型架构中（包括后处理），部署起来更加的自由可控                   | 需要根据wts的键值，使用tensorrt module来手动搭建网络，容错率较高且比较费时                 | 
| 常规trt                                                                               | pt ---> onnx ---> engine              | 可以使用tensorrt的paser api来自动解析模型结构以及对应的权重，生成engine，方便我们部署，减少工作量                   |  对于不支持的算子，在生成engine时会报错               |
